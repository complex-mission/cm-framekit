硬件加速编码（在本程序中的作用）

硬件加速 = 用显卡的专用单元来编码视频。在本程序里它只作用于「预览视频」的导出（生成预览视频时的编码环节），其中 H.265 提速最明显。

以下功能不受影响（与硬件加速无关）：

  • 截帧 / 画面预览：只解码和显示、不做编码，快慢与 GPU 加速无关。
  • 提取音频：是音频编码，不走视频硬件编码器。
  • 雪碧图：输出图片（WebP/JPG），也不走视频硬件编码器。

速度 vs 画质：硬件编码快很多、CPU 占用低；但同等设置下画质通常略低于 CPU 软件编码（libx264/libx265 压缩效率更高，同体积画质更好）。要快 → 选硬件；要画质/最小体积 → 选软件。

如何选择 / 不用 GPU：在「预览视频 → 编码」下拉里选。默认就是软件编码（H.265 软件），不会自动用 GPU；想用硬件就选下拉里出现的硬件选项，想关掉就保持「软件」选项即可。

标题栏徽章显示本机检测到的硬件编码器：AMF（AMD 显卡）、NVENC（NVIDIA）、QSV（Intel 核显）、VideoToolbox（macOS）；没有则显示「软件编码」。

视频编码：H.264 与 H.265

  • H.264：兼容性最好，几乎所有设备/浏览器都能播放。
  • H.265（HEVC）：相同画质下体积约小一半，但更吃编码性能，部分老设备/浏览器不支持。

输出格式：MP4 / GIF / WebP

  • MP4：通用视频，体积最优、可含音频。
  • GIF：兼容性最好，但仅 256 色、体积偏大、无音频。颜色数越少体积越小。
  • WebP 动图：比 GIF 更小、色彩更好；但大尺寸/长时长动画在 Safari 下可能越播越慢甚至卡死，建议小尺寸、短时长、低帧率。

雪碧图 + VTT

雪碧图把多张缩略图拼到一张大图里；配套的 VTT 文件记录每个时间点对应缩略图在大图中的位置。播放器加载 VTT 后，鼠标悬停进度条即可显示预览缩略图（常见于各视频网站）。

帧率 (fps)

  • 原始帧率：与源一致，最流畅、体积最大。
  • 29.97：NTSC（北美/日本电视标准）；25：PAL（欧洲）；24：电影感。
  • 12–15：预览/缩略够用，体积明显更小。

截帧导出

  • 尺寸按高度等比缩放，只缩小不放大（如 4K 源导出 720p 海报）。
  • 格式：PNG 无损、体积最大；JPG / WebP 可调画质、体积更小。
  • 所有产物都会存进以视频文件名命名的文件夹，多次导出自动接续编号、不覆盖。
